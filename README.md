# Rock_Paper_Scissor# 🎮 Rock Paper Scissors

> A simple and interactive **Rock Paper Scissors game built with Python** 🎯

## 🌟 About the Project

Rock Paper Scissors is a classic game where the player competes against the computer.

The computer randomly chooses **Rock, Paper, or Scissor**, while the player makes their own choice. The program compares both choices, determines the winner, and keeps track of the score throughout the game.

This project was created as a **beginner-friendly Python project** to practice programming logic and build an interactive console-based application.

## ✨ Features

- 🎮 Player vs Computer gameplay
- 🤖 Random computer choices
- 🏆 Automatic winner detection
- 📊 Real-time score tracking
- 🔄 Play multiple rounds
- ❌ Invalid input handling
- 🔤 Supports uppercase and lowercase input
- 🧹 Handles extra spaces in user input
- 🏁 Displays the final score and overall result

## 🧠 Game Rules

| Player | Computer | Result |
|--------|----------|--------|
| Rock | Scissor | 🏆 Player Wins |
| Paper | Rock | 🏆 Player Wins |
| Scissor | Paper | 🏆 Player Wins |
| Same Choice | Same Choice | 🤝 Draw |
| Other Combinations | — | 🤖 Computer Wins |
